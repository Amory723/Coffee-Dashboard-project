# Coffee Sales Dashboard

## Project Overview
An Excel dashboard that summarizes coffee sales, orders, and customer purchasing patterns.

![Coffee Sales Dashboard]

## Key Metrics
- **Total Sales:** $42,627.6
- **Total Orders:** 1313
- **Items:** 8
- **Average Sales:** 32.5

## Analysis Included
- Most popular coffee
- Orders by shift
- Orders by payment method
- Orders by month
- Orders by day

## Key Observations
- Americano is shown as the most popular coffee.
- The dashboard compares order volumes across morning, midday, and evening shifts.
- Payment methods are displayed in a doughnut chart.
- Monthly order counts fluctuate, with a peak in May.
- The treemap compares orders across days of the week.

## Tools Used
- Microsoft Excel
- Dashboard charts and KPI cards
- Data visualization

## How to Use
1. Open the Excel workbook.
2. Review the dashboard and its charts.
3. Use the filters to explore sales and order patterns.
